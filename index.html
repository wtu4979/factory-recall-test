Dashboard Alert Recall Test

A short memory task for a Georgia Tech cognitive science class project

Before you start

This is a short memory test. You will see lists of factory-style alert names on the screen for a few seconds, then type back as many as you can remember. It takes about 10 minutes.

Your participation is voluntary and you can stop at any time by closing the page. No names or personal information are collected. Your results are linked only to a random code. The researcher will use the results, together with other participants' results, in a class project report.

Please do not write anything down while the alerts are on screen, and do not take screenshots.

How it works

Each round, a factory dashboard will show a list of alerts for 8 seconds. Then it disappears. Type back every alert you remember.

Each alert is a single word, like a machine part. Type one word per line, in any order, like this:

TURBINE

Guessing is fine. Small typos are OK. After each round you will see which alerts you got right (green) and which you missed (red).

First you will do one practice round that does not count. Then there are 10 scored rounds. The lists get longer as you go. Some rounds show the alerts grouped under labels like FLUID or SAFETY, and some show them in a plain list.
